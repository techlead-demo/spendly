Edit expense

Delete this expense? This cannot be undone.

Wireframe (SPD-3). Shown here: the confirmation step after "Delete" was clicked on project-context/design/screens/expense-form-edit.html. The confirmation replaces the Save / Cancel / Delete row; focus moves to "Keep". "Keep" returns to the form with the row Save / Cancel / Delete and the field values unchanged. "Delete expense" removes the expense and returns to the expense list. While the delete request runs, both buttons are disabled. If it fails, the form shows the error banner of expense-form-errors.html at the top of the card with "Could not delete the expense. Try again." and the row Save / Cancel / Delete again.
